ТРЕБОВАНИЕ: Отмена бронирования и возврат средств
Проект: StayNow — сервис бронирования отелей
Версия документа: 2.0
Автор: Аналитик команды Booking
Статус: На ревью

---------------------------------------------------------------
1. ОПИСАНИЕ
---------------------------------------------------------------
Гость может отменить своё бронирование в личном кабинете или через
мобильное приложение. В зависимости от того, сколько времени осталось
до заезда, гостю возвращается полная стоимость, часть стоимости или
ничего.

Менеджер отеля в партнёрском кабинете тоже может отменить бронирование,
например если номер недоступен по техническим причинам.

Возврат средств выполняется через платёжный шлюз на карту, которой
было оплачено бронирование.

---------------------------------------------------------------
2. БИЗНЕС-ПРАВИЛА
---------------------------------------------------------------
BR-1. Отменить можно только бронирование в статусе CONFIRMED.

BR-2. Бесплатная отмена возможна не позднее чем за 48 часов до заезда.
      В этом случае гостю возвращается полная стоимость бронирования.

BR-3. При отмене менее чем за 48 часов, но более чем за 24 часа до
      заезда, возвращается 50% стоимости бронирования.

BR-4. При отмене менее чем за 24 часа до заезда возврат
      не производится.

BR-5. Сервисный сбор StayNow (5% от стоимости) не возвращается.

BR-6. При отмене бронирования менеджером отеля гостю возвращается
      полная стоимость.

BR-7. Бронирование может включать несколько номеров. Отмена
      выполняется для бронирования целиком.

BR-8. После отмены гостю отправляется письмо с подтверждением
      и суммой возврата.

---------------------------------------------------------------
3. РАСЧЁТ ВОЗВРАТА (справочно для разработки)
---------------------------------------------------------------
| Время до заезда   | Возврат           |
|-------------------|-------------------|
| 48 часов и более  | 100%              |
| менее 48 часов    | не производится   |

---------------------------------------------------------------
4. ПОЛЯ
---------------------------------------------------------------
Сущность Booking (фрагмент):
| Поле           | Тип     | Описание                                 |
|----------------|---------|------------------------------------------|
| id             | integer | идентификатор бронирования               |
| status         | enum    | PENDING / CONFIRMED / CANCELLED /        |
|                |         | COMPLETED                                |
| checkin_date   | string  | дата заезда                              |
| checkout_date  | string  | дата выезда                              |
| total_price    | number  | стоимость бронирования                   |
| guest_id       | integer | идентификатор гостя                      |

Сущность Refund:
| Поле           | Тип     | Описание                                 |
|----------------|---------|------------------------------------------|
| booking_id     | integer | идентификатор бронирования               |
| amount         | number  | сумма возврата                           |
| status         | enum    | PENDING / COMPLETED                      |
| created_at     | string  | дата создания возврата                   |

---------------------------------------------------------------
5. API
---------------------------------------------------------------
5.1. Отменить бронирование

POST /api/v1/bookings/{bookingId}/cancel

Заголовки:
  Authorization: Bearer <token>

Тело запроса:
{
  "reason": "Изменились планы"
}

Поле reason — необязательное, причина отмены в свободной форме.

Успешный ответ — 200 OK:
{
  "bookingId": 90417,
  "status": "CANCELLED",
  "refund": {
    "amount": 7600,
    "status": "PENDING"
  }
}

Ошибки:
  404 Not Found  — бронирование не найдено
  409 Conflict   — бронирование уже отменено

---------------------------------------------------------------
6. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
---------------------------------------------------------------
NFR-1. Возврат поступает на карту гостя в течение 5–10 рабочих дней.
NFR-2. Время ответа POST /cancel — не более 1 секунды.
