# Petstore API, коллекция Postman 
(раздел Pet)

Учебный проект по тестированию API сервиса Swagger Petstore в Postman.
Проверяю создание, поиск, изменение и удаление питомцев, а также загрузку фотографии.

## Что есть в проекте

- Positive tests — 11 проверок с корректными данными.
- Negative tests — 9 проверок с некорректными данными или отсутствующей записью.
- E2E — папка последовательных сценариев. Пока внутри один: Pet life cycle, 7 шагов от создания питомца до удаления через API.

Позитивные и негативные запросы можно запускать отдельно: каждый сам готовит нужные данные. После проверки тестовые записи удаляются.
Проверяются коды ответов, структура и содержимое данных, а также сохранение изменений на сервере.

## Как запустить

1. Импортировать Petstore.postman_collection.json в Postman.
2. При желании импортировать Petstore.postman_environment.json. Адрес API уже задан и в коллекции.
3. Выбрать запрос и нажать Send. В E2E открыть Pet life cycle и запустить эту вложенную папку целиком через Run folder, начиная с первого шага.
4. Для Upload a pet photo выбрать файл fixtures/pixel.png в Body → form-data → file.

## Результат проверки

Проверено 11 ноября 2026 года через Newman: все позитивные проверки и сценарий Pet life cycle прошли.
Семь негативных проверок выявили расхождения между документацией API и поведением публичного сервера.
Отдельно проверен запуск каждого независимого запроса.
