# QA Portfolio

Учебное портфолио по ручному и авто тестированию API и Backend.

## Разделы

| Раздел | Что внутри |
|--------|------------|
| [requirements-analysis](requirements-analysis/) | Анализ требований: поиск дефектов в ТЗ и уточняющие вопросы к аналитику, разработчику и бизнесу |
| [acc-practice](acc-practice/) | Риск-анализ продукта по ACC (Google): компоненты × атрибуты качества ISO/IEC 25010, 25012, 25059, оценка риска (частота × ущерб) и что проверять в каждой паре |
| [api-tests-restful-booker](api-tests-restful-booker/) | Автотесты REST API бронирований: Python, pytest, requests, pydantic. Авторизация, CRUD, позитивные и негативные кейсы |
| [petstore-postman](petstore-postman/) | Коллекция Postman для Petstore API: позитивные и негативные проверки, подготовка и очистка тестовых данных, последовательный сценарий Pet life cycle |
