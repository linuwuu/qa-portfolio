ТРЕБОВАНИЕ: Применение промокода к заказу
Проект: ShopLine — интернет-магазин бытовой техники
Версия документа: 1.2
Автор: Аналитик команды Checkout
Статус: На ревью

---------------------------------------------------------------
1. ОПИСАНИЕ
---------------------------------------------------------------
Покупатель может применить промокод к своему заказу, чтобы получить
скидку. Промокод вводится на странице оформления заказа. Скидка
пересчитывается сразу после применения, итоговая сумма заказа
обновляется.

Промокоды создаёт маркетолог в админ-панели. Администратор может
деактивировать промокод в любой момент.

Сотрудник поддержки может применить промокод к заказу клиента по его
обращению.

---------------------------------------------------------------
2. БИЗНЕС-ПРАВИЛА
---------------------------------------------------------------
BR-1. Промокод можно применить только к заказу, который ещё не оплачен.

BR-2. Промокод бывает двух типов:
      - percent — скидка в процентах от суммы заказа;
      - fixed   — фиксированная скидка в рублях.

BR-3. Минимальная сумма заказа для применения промокода — 1000 ₽.

BR-4. К одному заказу можно применить только один промокод.

BR-5. Один пользователь может использовать промокод только один раз.

BR-6. Промокод действует до даты окончания действия (valid_until).

BR-7. Промокод не суммируется с другими акциями магазина.

BR-8. Общее количество использований промокода ограничено полем
      total_limit. Когда лимит исчерпан, промокод перестаёт работать.

---------------------------------------------------------------
3. ПОЛЯ ПРОМОКОДА (сущность PromoCode)
---------------------------------------------------------------
| Поле           | Тип     | Обяз. | Ограничения / описание                 |
|----------------|---------|-------|----------------------------------------|
| code           | string  | да    | 6–12 символов, латиница и цифры        |
| type           | enum    | да    | percent / fixed                        |
| discount_value | number  | да    | для percent: 1–100                     |
|                |         |       | для fixed: 100–10000                   |
| valid_until    | string  | да    | дата окончания действия                |
| total_limit    | integer | нет   | общее кол-во использований             |
| per_user_limit | integer | да    | кол-во использований одним             |
|                |         |       | пользователем, 1–5                     |
| is_active      | boolean | да    | по умолчанию true                      |

---------------------------------------------------------------
4. API
---------------------------------------------------------------
4.1. Применить промокод

POST /api/v1/orders/{orderId}/promo

Заголовки:
  Authorization: Bearer <token>

Тело запроса:
{
  "code": "AUTUMN2026"
}

Успешный ответ — 200 OK:
{
  "orderId": 58213,
  "code": "AUTUMN2026",
  "subtotal": 12500,
  "discount": 1875,
  "total": 10625
}

Ошибки:
  404 Not Found            — заказ не найден
  404 Not Found            — промокод не найден
  422 Unprocessable Entity — сумма заказа меньше минимальной

4.2. Удалить промокод из заказа

DELETE /api/v1/orders/{orderId}/promo

Успешный ответ — 204 No Content.

---------------------------------------------------------------
5. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
---------------------------------------------------------------
NFR-1. Время ответа POST /promo — не более 500 мс (95-й перцентиль).
NFR-2. Все попытки применения промокода логируются.
